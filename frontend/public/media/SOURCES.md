# Landing hero reel

Six films of engineers reviewing plans on site, behind the landing hero. They are tinted and
lightly softened in the page, so they are kept at 960x540 rather than at full size; the reel
fetches each film only when it is about to appear, and the leanest one opens so the page loads
under a megabyte of video.

required, modification allowed. The reel is named in VITE_LANDING_VIDEO_URL as a comma-separated
list, so a deployment can swap in the company's own footage, or serve these from object storage,
without a code change.
